⚙️ Giải Thích Storage Configuration

Hiểu rõ cách cấu hình và tối ưu hóa kho hàng

1. ABC Classification - Phân Loại Sản Phẩm

🎯 Mục Đích

Phân loại sản phẩm theo tần suất xuất kho để đặt sản phẩm quan trọng ở vị trí dễ tiếp cận nhất.

💡 Nguyên Tắc 80-20 (Pareto):
20% sản phẩm chiếm 80% lượng xuất kho → Đặt gần nhất!
Class Tỷ Lệ Sản Phẩm Tần Suất Xuất Vị Trí Lưu Trữ Ví Dụ
Class A 20% 80% lượng xuất Zone A, B, C (gần nhất) Laptop, điện thoại hot
Class B 30% 15% lượng xuất Zone D, E, F, G (trung bình) Phụ kiện thông dụng
Class C 50% 5% lượng xuất Zone H-R (xa nhất) Hàng ít bán, dự trữ

📝 Ví Dụ Thực Tế

Trước khi cấu hình:

  • Laptop (bán 50 cái/ngày) đang ở Zone R (xa 350m)
  • Nhân viên phải đi 350m × 50 lần = 17,500m/ngày!

Sau khi cấu hình ABC:

  • AI phát hiện Laptop nên là Class A
  • Hệ thống đề xuất chuyển sang Zone A (gần 50m)
  • Tiết kiệm: 50m × 50 lần = 2,500m/ngày (giảm 85%!)

⚙️ Cách Cấu Hình

Đặt Threshold (Ngưỡng)

Class A Threshold: 20% → Top 20% sản phẩm có tần suất cao nhất

Class B Threshold: 50% → 30% tiếp theo (từ 20% đến 50%)

Còn lại 50% là Class C

AI Tự Động Phân Loại

Hệ thống chạy K-Means algorithm để phân tích tần suất picking và tự động gán ABC code cho từng sản phẩm

Áp Dụng Vào Kho

Sản phẩm Class A được đề xuất chuyển sang Zone A, B, C (gần khu picking)

2. Storage Strategy - Chiến Lược Lưu Trữ

🎯 Mục Đích

Chọn phương pháp tổ chức kho phù hợp với đặc điểm hàng hóa và quy trình làm việc.

Strategy Đặc Điểm Ưu Điểm Nhược Điểm Khi Nào Dùng
Class-Based Phân zone theo ABC Giảm thời gian picking Cần phân loại chính xác Hàng có tần suất rõ ràng
Dedicated Mỗi sản phẩm 1 vị trí cố định Dễ tìm, dễ quản lý Lãng phí không gian Ít SKU, ổn định
Random Đặt bất kỳ chỗ trống nào Tối ưu không gian Khó tìm, cần WMS tốt Nhiều SKU, thay đổi nhanh
Hybrid Kết hợp các phương pháp Linh hoạt, cân bằng Phức tạp hơn Kho lớn, đa dạng

📝 Ví Dụ: Chọn Strategy Nào?

Scenario 1: Kho điện tử

  • 208 sản phẩm, tần suất rõ ràng (laptop hot, phụ kiện ít)
  • → Dùng Class-Based Storage
  • → Laptop (Class A) ở Zone A, phụ kiện (Class C) ở Zone R

Scenario 2: Kho thời trang

  • 5000 SKU, thay đổi theo mùa
  • → Dùng Random Storage
  • → Đặt bất kỳ đâu, WMS tracking vị trí

Scenario 3: Kho tổng hợp

  • Vừa có hàng hot, vừa có hàng ít bán
  • → Dùng Hybrid Strategy
  • → Top 50 SKU dùng Dedicated, còn lại dùng Random
🤖 AI Tự Động Đề Xuất:
Hệ thống phân tích dữ liệu và đề xuất strategy phù hợp nhất. Ví dụ: "Nên dùng Hybrid vì có 20% sản phẩm chiếm 80% picking"

3. Zone Configuration - Cấu Hình Zones

🎯 Mục Đích

Phân chia kho thành các zones và gán mục đích sử dụng cho từng zone.

High-Frequency Zone

Zone A, B, C

Gần khu picking

Class A products

Medium-Frequency Zone

Zone D, E, F, G, H

Khoảng cách trung bình

Class B products

Low-Frequency Zone

Zone I-R

Xa khu picking

Class C products

📝 Ví Dụ Layout Kho

┌─────────────────────────────────────────┐
│  PICKING AREA (Khu lấy hàng)           │
├─────────────────────────────────────────┤
│  Zone A  │  Zone B  │  Zone C          │  ← High-Frequency (gần)
│  (Class A products)                     │
├─────────────────────────────────────────┤
│  Zone D  │  Zone E  │  Zone F  │ Zone G│  ← Medium-Frequency
│  (Class B products)                     │
├─────────────────────────────────────────┤
│  Zone H  │  Zone I  │  Zone J  │ Zone K│
│  Zone L  │  Zone M  │  Zone N  │ Zone O│  ← Low-Frequency (xa)
│  Zone P  │  Zone Q  │  Zone R          │
│  (Class C products)                     │
└─────────────────────────────────────────┘

⚙️ Cách Cấu Hình

Chọn High-Frequency Zones

Chọn zones gần khu picking nhất (A, B, C) để đặt sản phẩm Class A

Chọn Low-Frequency Zones

Chọn zones xa (D-R) để đặt sản phẩm Class C

AI Tự Động Phân Bổ

Khi nhập hàng mới, AI tự động đề xuất zone phù hợp dựa trên ABC class

4. Cách 3 Phần Hoạt Động Cùng Nhau

Nhập Hàng Mới

Nhân viên nhập 100 units sản phẩm "LAPTOP-001"

AI Phân Tích

- Kiểm tra lịch sử: Sản phẩm này được pick 45 lần/tuần
- Chạy K-Means: Xếp vào top 10% → Class A
- Kiểm tra Strategy: Đang dùng Class-Based Storage

Tìm Vị Trí

- Kiểm tra Zone Config: Class A nên ở Zone A, B, C
- Tìm vị trí trống: Zone A-01-05 còn trống 80%
- Tính khoảng cách: 50m từ khu picking

Đề Xuất

AI hiển thị: "Đề xuất lưu tại A-01-05"
Lý do: Class A, gần nhất, còn trống
Lợi ích: Giảm 85% quãng đường picking

Nhân Viên Xác Nhận

Click "Apply" → Hệ thống tự động:
- Cập nhật location: A-01-05
- Cập nhật occupancy: 80% → 100%
- Ghi log: "Đã lưu theo đề xuất AI"

✅ Kết Quả:
Sản phẩm được đặt đúng vị trí tối ưu ngay từ đầu, không cần di chuyển sau này!
